# Roxwood Digital Forge

Tu es un expert en développement web (HTML, CSS, JavaScript, animations smooth, transitions modernes, responsive design, UI/UX premium, design d’agence digitale).

Ta mission : créer un site complet, rofessionnel, immersif et démonstratif pour “Roxwood Network”, une agence digitale RP opérant sur le serveur GTA 5 Flashback FA. Il faut savoir que cet entreprise existe reelement dans le jeu donc ecris pas " GTA 5 FLASHBACK FA " dans le site sinon ca serai totalementr HRP
C Ce site doit servir de vitrine pour montrer notre savoir-faire, notre identité visuelle, et les différents types de sites que nous pouvons concevoir pour les entreprises, commerces, agences et organisations (légales ou illégales).

Identité visuelle (à respecter impérativement) :
- S’inspirer du logo Roxwood Network (couleurs, ambiance, style). Et également de leur site qui ont déja : https://roxwood-network.fbfa.fr/
- Style : agence digitale premium, tech, moderne, légèrement RP.
- Couleurs dominantes : celles du logo (bleu nuit / cyan / blanc / gris foncé).
- Polices : “Poppins” pour les titres, “Inter” pour les textes.
- Atmosphère : professionnelle, immersive, sérieuse, haut de gamme.

Structure du site (multi-pages) :

   - Hero section immersive :
       Titre : “Roxwood Network — Agence Digitale RP”
       Sous-titre : “Nous créons des sites immersifs pour entreprises, agences et organisations sur Flashback FA.”
       Boutons :
         - “Voir nos réalisations”
         - “Nous contacter”
       Image de fond : ambiance urbaine / skyline RP (placeholder).
       Animations : fade-in + parallax + glow léger.
   - Section “Notre expertise”
       3 blocs :
         - “Sites vitrines professionnels”
         - “Portails RP pour agences et services”
         - “Interfaces pour organisations illégales (RP)”
       Icônes stylées (placeholders) + hover effect.
   - Section “Pourquoi Roxwood Network ?”
       Points :
         - “Design immersif adapté au RP”
         - “Intégration bot GitHub / Discord”
         - “Systèmes internes et accès restreints”

       Cartes premium :
         - “Entreprise légale”
         - “Agence publique”
         - “Organisation illégale”
       Chaque carte : description + bouton “Voir un exemple”.

   - Titre : “Nos Services”

4. Page Espace Membre (membres.html)

Contraintes générales :
- Code propre, commenté, organisé.
- Design premium, cohérent avec le logo Roxwood Network.
- Version mobile obligatoire (responsive).
- Utiliser uniquement HTML/CSS/JS (pas de framework).
- Ajouter des placeholders pour les images.
- Header + footer commun sur toutes les pages.
- Navigation fluide entre les pages.
- Animations smooth (fade, slide, hover, glow).
- Portfolio navigable avec liens externes en nouvel onglet.
- Page preview pour un rendu professionnel.
- Espace membre réaliste avec logique de connexion + dashboard.
- Intégration fictive mais sérieuse du bot GitHub.
- Optimiser pour un rendu haut de gamme, immersif, démonstratif et adapté au RP.
